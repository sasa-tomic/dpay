# Name decision — ∂ifferent Pay (2026-08-17)

**Decision (founder-set 2026-08-17, after full USPTO + TMview + DNS + app-store clearance):**

| Surface | Name |
|---|---|
| Product name (display) | **∂ifferent Pay** (long form: Different Pay) |
| Short name (display) | **∂pay** |
| Short name (typed / technical) | **dpay** — unchanged everywhere |
| Spoken name | **"dee-pay"** (unchanged) |
| Slogan | **"Pay differently."** |

`∂` (U+2202) is a **logo glyph, not a character anyone types**. All technical surfaces stay ASCII `dpay`: the Android package, the NFC AIDs, the repo, canister names, URLs, the launcher label, the app-store listing name (typed "Different Pay", dpay in the subtitle). Nobody can type ∂ on a common keyboard — so the typed brand is still dpay and everyone still says "dee-pay"; the glyph lives in the wordmark, the logo tile, and print.

## Why

- **The math story is the product.** Multi-currency, multi-chain (IC + Solana) = pay with many independent variables. ∂pay reads as "the partial derivative of pay" — the rate of change of paying. The glyph already had in-product meaning before the rename: **∂ is the demo-dollar symbol** in the app (onboarding: "∂ is the demo-dollar symbol — play money, ∂1 = $1"), so the logo and the currency language now rhyme.
- **"dpay" alone is legally untenable in payments.** Clearance found: USPTO **DPAY Reg 6721461 LIVE** (Allen Bates Technologies, cl 035/009/042, dues-payment software, registered 2022); class-36 `dpay` registrations in the EU (PAYMENTS LAB, EUIPO 019024691), Poland, Ukraine, Brazil, China (JD.com), Italy (DPAY SRL, 2024); Türkiye filed. Plus dpay.ly (TM'd gateway), Coca-Cola Japan dPay, a crypto token, an ETF ticker — and every `dpay.*` domain is held. OK as an internal identifier; not OK as *the brand*.
- **"Different Pay" is clear.** Zero exact `DIFFERENT PAY` marks at USPTO (7,541 contains-matches, none exact) and TMview global (19 contains-matches, none exact). `differentpay.{app,io,money,net,org,co,finance,xyz,dev}` all unregistered (only .com is held). Nearest live conflict is **PAY DIFFERENT** (Payzli Corp., US cl 036, sn 97093513) — reversed word order, same class; arguable, not a knockout, and the stylized ∂ composite weakens similarity further. Tencent's PAY DIFFERENT，LIVE DIFFERENT WEPASS is China-only.
- **Slogan cleared too:** "Pay differently" has no live mark anywhere (sole hit: WEX's ended "WE SEE CORPORATE PAYMENTS DIFFERENTLY"). "Pay different" is TAKEN (Payzli US + Tencent CN, both live cl 36) — never use the singular form.

## What was rejected

- **∂iff Pay / DiffPay** — collides head-on with a live DiffPay shift-earnings app (diffpay.app) and the HR "differential pay" meaning; the collapsed glyph also stops reading as a stylized D.
- **Fluxion / Nabla / DeltaV / Riemann** — good marks, but they discard the "dee-pay" brand equity and the ∂ continuity; kept in the brainstorm record, not chosen.
- **"Let's make a difference" / "Be different"** — NGO cliché / too vague. The slogan is "Pay differently."

## Where the ∂ glyph comes from

The logo ∂ is the DejaVu Sans Bold U+2202 outline (public-domain glyph shapes), re-fit to the existing tangerine tile geometry (height 500/1024, optical center 526/1024) — the same tile and porcelain-on-tangerine treatment as the previous "d", so the mark stays recognizably the same product, one glyph swapped. Rendering check: ∂ renders in Android/RN system fonts and in web core fonts — no custom font needed for the wordmark.

## Founder outer loop (not agent work)

1. Register `differentpay.app` + `differentpay.money` (+ optionally .io/.dev) as redirects — ~$50, 2 minutes.
2. Lawyer knockout search on the **∂ifferent Pay** stylized composite + **∂pay** design mark before any print run.
3. If clean: file intent-to-use TMs (cl 36/42/9) on the stylized composites — far more registrable than "dpay" ever was.
4. At listing time: app-store name typed as "Different Pay", dpay in the subtitle, ∂ only in the icon/screenshots (store search does not fold ∂→d).

## Surface rules (for future work)

- **Display surfaces** (wordmark, logo, landing page hero, print): ∂ifferent Pay / ∂pay, slogan "Pay differently."
- **Typed/technical surfaces** (package ids, AIDs, URLs, repo, code identifiers, launcher label, store listing name, NFC settings strings): ASCII `dpay` / "Different Pay" — the ∂ never appears where a user must type or search.
- **Prose**: "Different Pay" written out; never "partial payment" phrasing.
